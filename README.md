# 🌊 MorphFlow Transitions
### Experimental Blurred Page Transitions & Motion Choreography

An interactive frontend experiment exploring dynamic blurred page transitions, fluid layout choreography, and gesture-driven animations using **React 19**, **Motion** (Framer Motion), and **Tailwind CSS v4**.

---

## ⚡ Core Concepts

- **Fluid Layout Choreography**: Continuous layout animations across card expands, view switches, and modal reveals without layout shifts.
- **Backdrop Filter & Depth**: Layered frosted glass and blur transitions utilizing hardware-accelerated CSS filters.
- **Modern Build Stack**: Built with Vite and React 19 concurrent features.

---

## 🚀 Running Locally

```bash
# Clone the repository
git clone https://github.com/SohanV1/morphflow-transitions.git
cd morphflow-transitions

# Install dependencies
npm install

# Start local development server
npm run dev
```

---

## 🛠️ Tech Stack
- **Framework**: React 19 / TypeScript
- **Motion Engine**: Motion (Framer Motion v12)
- **Styling**: Tailwind CSS v4
- **Bundler**: Vite
